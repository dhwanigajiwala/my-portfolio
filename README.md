# Portfolio website (React + styled-components)

## 1. Make it yours
Open `src/data.js` and replace every placeholder: your name, role, email,
LinkedIn and GitHub URLs, about text, skills, projects, journey and the AI tools
you used. The whole site reads from that one file.

## 2. Run it on your computer
Install Node.js 18 or newer, then in this folder:

    npm install
    npm run dev

Open the address shown in the terminal.

## 3. Deploy on Vercel
1. Create a GitHub repository and push this folder to it.
2. Go to vercel.com, sign in with GitHub, and choose Add New > Project.
3. Import your repository. Vercel detects Vite automatically
   (build command `npm run build`, output directory `dist`).
4. Click Deploy. Your live link will look like https://your-project.vercel.app
5. Put that link and your repository link in your course document.

Every time you push to GitHub, Vercel redeploys automatically.
